# AI 纯净粘贴 - 聊天助手必备 (AI Pure Paste Chrome Extension)

## 📌 简介
这是一款专为各类 AI 聊天工具（如 ChatGPT, Gemini, Claude, Kimi, 文心一言等）打造的浏览器插件。功能非常简单直接：**当你向聊天框粘贴内容时，自动清除从网页、Word 等地方复制时附带的多余格式（HTML、内嵌样式）和无用图片，只保留干净纯粹的文本。** 让你体验真正的“纯净粘贴”，无论是发代码还是发长文，都更加干净利落。

## 🚀 核心功能
- **自动拦截并清理格式**：自动移除剪贴板富文本中的冗余样式与无用 img 标签。
- **保留文本换行**：在清理格式的同时，完美保留原本的段落结构和换行符。
- **无感运行**：基于 Chrome V3 Manifest 打造的纯本地轻量级插件，开销极低。
- **多平台支持**：预设匹配目前主流各家 AI 对话平台（如 ChatGPT, Gemini, Claude, 等）。

## 💡 安装步骤
1. 下载或克隆本仓库到本地。
2. 打开 Chrome 或其他 Chromium 内核浏览器的扩展程序页面：`chrome://extensions/` （Edge: `edge://extensions/`）
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，并选择本插件所在的文件夹即可使用。
