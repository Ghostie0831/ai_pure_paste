## 📌 Introduction
This is a lightweight browser extension designed specifically for AI chat platforms (such as ChatGPT, Gemini, Claude, etc.). Its function is simple and direct: **When you paste content into the chat box, it automatically strips away unnecessary formatting (HTML, inline styles) and useless images copied from webpages or Word documents, leaving only clean, pure text.** Experience true "pure pasting", whether you are sending code or long articles, keeping your conversations tidy.

## 🚀 Core Features
- **Auto-Intercept & Clean Formatting**: Automatically removes redundant styles and useless `img` tags from rich text in the clipboard.
- **Preserves Line Breaks**: While cleaning formats, it perfectly preserves original paragraph structures and line breaks.
- **Silent Operation**: A purely local, lightweight extension built on Chrome V3 Manifest with extremely low overhead.
- **Multi-Platform Support**: Pre-configured to match major AI chat platforms (e.g., ChatGPT, Gemini, Claude, etc.).

## 💡 Installation
1. Download or clone this repository to your local machine.
2. Open the extensions page in Chrome or any Chromium-based browser: `chrome://extensions/` (Edge: `edge://extensions/`)
3. Enable "Developer mode" in the top right corner.
4. Click "Load unpacked" and select the folder of this repository to start using it.
